# AI Mascots — питомцы на экране телефона

Android-приложение: маскоты ИИ гуляют поверх всех приложений.

- 🦀 **Clawd** — оранжевый краб-пиксель из Claude Code (персонаж Anthropic)
- 🦊 **Лиса Vibe** — рыжая лисичка (спрайт сгенерирован ИИ)
- 🐋 **Кит DeepSeek** — синий кит (спрайт сгенерирован ИИ)

## Возможности

- Маскот свободно гуляет по всему экрану поверх других приложений
- Смена маскота кнопками в уведомлении (Назад / Вперёд / Стоп)
- Тап по маскоту — приветственная анимация + вибрация
- Перетаскивание пальцем в любое место
- Clawd анимирован кадрами (ходьба / приветствие / idle), лиса и кит — плавный бобинг, наклоны и прыжок

## Установка (без ПК)

1. Скачайте `AiMascots.apk` из этого репозитория (в браузере телефона: открыть файл → Download)
2. Откройте скачанный файл, разрешите установку из источника
3. При первом запуске: «Разрешить поверх окон» → включите тумблер для приложения
4. Нажмите «Запустить маскотов» — маскот появится на экране
5. Смена маскота — в шторке уведомлений

## Сборка

Нужен JDK 17 и Android build-tools 34 + платформа android-34:

```bash
ANDROID_TOOLCHAIN=/path/to/toolchain ./build.sh
```

Тулчейн ожидается в такой структуре (как в build.sh):

```
toolchain/
  jdk-17.../           JDK
  android-14/          build-tools 34 (aapt2, d8, apksigner, zipalign)
  android-34/android.jar
```

APK собирается вручную: aapt2 → javac → d8 → zipalign → apksigner. Без Gradle.
