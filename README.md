# NEON HORIZON

Детализированная 3D-игра на мобильный телефон: бесконечный полёт сквозь неоновый каньон.
Работает в любом современном браузере, без установки — просто откройте страницу.

## Запуск

Нужен любой статический HTTP-сервер (из-за ES-модулей нельзя открывать файл напрямую):

```bash
python3 -m http.server 8080
# или
npx serve .
```

Затем откройте `http://localhost:8080` на компьютере или `http://<IP-компьютера>:8080` в браузере телефона (в той же Wi-Fi сети).

## Управление

| Действие | Телефон | Клавиатура / мышь |
|---|---|---|
| Полёт | свайп в любом месте экрана | WASD / стрелки, зажатая ЛКМ |
| Ускорение | кнопка BOOST справа снизу | SHIFT или ПРОБЕЛ |
| Пауза | кнопка ⏸ | P / ESC |

## Игровые механики

- **Кристаллы** — очки, заряд ускорения; каждые 12 кристаллов дают +1 щит
- **Врата** (кольца) — пролетите сквозь них для бонуса
- **Ускорительные площадки** — мгновенный полный заряд BOOST
- **Комбо-множитель** — до x5 за серию сборов, сбрасывается при столкновении
- **Щиты** — 3 при старте, максимум 4; столкновение отнимает один
- Сложность и скорость растут с дистанцией

## Графика

- PBR-материалы с процедурным окружением (PMREM-отражения на корпусе)
- Динамические мягкие тени (PCFSoft)
- Постобработка: UnrealBloom, ACES Filmic tone mapping, sRGB output
- Кастомные шейдеры: небо с полярным сиянием, бесконечный светящийся пол-сетка
- Ленточные шлейфы двигателей, GPU-частицы, тряска камеры, FOV-кик на ускорении
- Три пресета качества + автоматическое снижение при низком FPS

## Аудио

Полностью процедурный синтез через Web Audio API: гул двигателя, привязанный к скорости, арпеджио-музыка, звуки сборов, столкновений и ускорения. Никаких внешних файлов.

## Структура

```
index.html          — разметка, HUD, importmap
css/style.css       — интерфейс и анимации
js/main.js          — точка входа
js/game.js          — состояние, цикл, камера, постобработка
js/world.js         — небо, пол, стены каньона, горы, свет
js/player.js        — корабль, трейлы, инерция
js/obstacles.js     — пулы препятствий, спавн-директор, коллизии
js/effects.js       — частицы, шлейфы, текстуры
js/input.js         — тач/мышь/клавиатура
js/audio.js         — процедурный Web Audio синтез
vendor/             — three.js r160 (локально, без CDN)
```

## Технологии

- Three.js r160 (локальный vendored-модуль, без сборки и CDN)
- Чистый ES-модульный JavaScript
- WebGL2 / Web Audio API
